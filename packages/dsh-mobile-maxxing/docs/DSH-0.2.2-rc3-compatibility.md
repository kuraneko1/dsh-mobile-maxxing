# DSH 0.2.2-rc.1 / rc.3 compatibility — unreleased

この変更は未公開です。バージョンの変更、既存インスタンスへの配信、リリースは行いません。

## 修正

- 通知の通常セッション判定から、rc.3で削除されたAgentRegistry.roots()への依存を外す。header.originがsubagentのものを除外し、親を持つ通常のforkは除外しない。
- 質問通知の準備・送信をbest-effortに分離する。レジストリ参照などが失敗しても、本来の回答処理のnext()を止めたり再実行したりしない。
- 質問・計画レビューの装飾は、cardの直親がframeである場合に限定する。承認のrootからアプリ全体のframeまで祖先探索をしない。不要になったframe/card属性も解除する。
- 以前追加したComposerメトリクスの再計測と180msの再実行を削除する。承認表示でseatは置換されておらず、上流のResizeObserverだけで高さが戻ることを新旧版の実UIで確認する。
- rc.3のdata-subagent-count / data-job-countを使い、言語やaria-haspopupのtree→dialog変更に依存せずチップを識別する。子エージェントのパンくず切替は装飾しない。
- 共有タスクがある場合は上流の見出しを利用する。既存の進捗・タスクfooter・見出しを消さず、実行中優先ソートの自前ボタンだけを追加・解除する。
- rc.3のモデルメニューはCSSアンカーを残す。安全領域に合わせてアンカーの水平制約と幅を補正し、上流の縦方向配置をピクセル座標で上書きしない。旧版のinline配置への補正は維持する。

## 維持する既存改善

- 端末判定と画面幅の分離、PC no-op、PWAの起動・キャッシュ・通知遷移。
- 端末ごとの言語・フォント・テーマ・権限、キーボード・safe-area・回転・入力の保護。
- ドロワーのtouch操作、開く際のキーボード処理、新規セッションで閉じる動作、スクロール位置・実行中リストの描画。
- ワークスペースの全セッション表示、タイトルの空状態を基準にしない処理、リングのセッション対応、一覧のソート。
- 設定への直接アクセス、横向きのその他メニュー、モデル検索のタップ後フォーカス維持。
- Todo / Goal / Queue、編集・差分、画像crop/pan・長押し・成果物保存、Markdown表、ターミナルのキー・幅fit。
- 初回openの監視・resync、前面ACK・背面Push・送信元対応・購読復旧、既存の描画・通信の節約。
- 上流に日本語がある場合に古い日本語辞書で上書きしない処理、更新UIのdismiss・完了表示、貢献者の記載。

新規セッション行に追加されたsidebar.session.actionは差し戻さない。公式DeepSeek取り込みプラグインを有効にした隔離QAで、8言語の新規セッション・取り込みボタン、取り込みダイアログ、横向き表示が利用可能なことを確認する。

## 回帰テスト

通常のテスト:

~~~sh
npm test
npm run test:locale
~~~

実スロットのテストは通常実行時にスキップされる。既存ユーザーのインスタンスではなく、作業中プラグインを読み込んだ新旧の隔離DSHと、管理下のheadless Chromeを準備して実行する。

~~~sh
DSH_COMPAT_URLS='["http://127.0.0.1:3191/?token=<QA token>","http://127.0.0.1:3193/?token=<QA token>"]' \
DSH_COMPAT_CDP=http://127.0.0.1:9457 \
node --test packages/dsh-mobile-maxxing/tests/approval-slot.browser.test.mjs
~~~

- 新規タブだけを作成して閉じる。接続先のChrome本体や他のタブは閉じない。
- キャッシュ・Service Workerを迂回し、初期化成功とセッションの結合を待つ。
- 本物のApprovalPanelを既存Composer slot経由で表示する。表示用入力だけを与え、ツール実行・許可・拒否の送信は行わない。
- 実際のdecorate処理を実行し、表示前・表示中・除去後の横幅、左端、frame属性、同一seat、高さの収束を比較する。初期化・描画のconsole.errorも失敗扱いにする。

追加の隔離実UI検証では、8言語、390px縦向き・844px横向き、220pxの狭幅モデルメニュー、390pxと1440pxのPCモードを確認する。PCではモバイルstylesheet・frame属性・FABが存在しないことを検査する。

## 公開前に残ること

- iOS / Android実機、ホーム画面アプリ、実キーボード・notch・OSのジェスチャーで確認する。Chromeの端末エミュレーションだけを実機確認とは扱わない。
- 実Push配送は暗号化・ACK・送信元対応等の回帰テストを通すが、今回実際のPushサービスへ通知は送らない。
- 上流の取り込み処理そのものや実アカウント接続は今回の修正対象ではない。テストでファイルのアップロードは行わない。
- 撤回済みv1.0.7の版表記・インストーラー参照は既存状態のまま。次の公開版と配布先はユーザー承認後に整合させる。このブランチを公開済みv1.0.7と扱わない。
